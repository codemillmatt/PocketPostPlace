We are creating a very simple blog. It will consist of the following features.

1. A home page that shows the title of every post as a list.
1. A details page that lets you read the post.
1. A way to enter a new post. All posts will only be text only.
1. All posts will be saved as markdown files and should be rendered appropriately.
1. This will be deployed as a github pages application.
1. Use Astro as the frontend.
1. Make the user interface clean and simplistic.
